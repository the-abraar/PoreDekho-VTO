# Seller pilot kit

Goal: you send 10 seller messages in under 30 minutes. Everything here is a draft for you to send from your own accounts; nothing has been sent.

## Files
- `message_en.md`, `message_bn.md`: the first message (under 90 words). Change only the page name.
- `pilot_terms.md`: send after a seller says yes (5 pieces, 4-6 weeks, free, the data asked, how to stop).
- `sku_photo_checklist.md`: send with the terms.
- `tracker.csv`: empty template, one row per seller from "found" to "stopped". This repo is public: copy it to `tracker.local.csv` (git-ignored) or a private sheet and fill that copy, never this file.

## 30-minute run (10 messages)
1. **10 min, find 10 pages** (sources below). Keep a page if: it sells earrings or necklaces, posted in the last 2 weeks, and people ask for prices in the comments. Add a row to your private copy of the tracker for each.
2. **15 min, send.** Open each page's Messenger (or the WhatsApp number on the page), paste the message in the page's language, change the name, send. Fill `sent_on`.
3. **5 min, follow up next day** only if they read it and did not reply. One follow-up, then stop.

Before the first yes: record a 20-30 second screen video of `tryon.html` with one of your own pieces (the message offers it).

## Rules
- Never name a seller's page publicly or in any committed file without written permission. Seller names go only in the private tracker copy.
- No numbers or results in messages until the pilot measures them (`docs/claims_to_verify.md`).
